# 中文报告、运行命名与双语文档设计

用户已在讨论后授权实施并提交远程；本文件记录已确认方案及对最新代码 `03ae3a1` 的复核结果。

## 目标与约束

- 每轮 Markdown 验证报告使用中文，参考指定 TSDB 双活报告的结构，在开头增加简短结果汇总表；自然语言阶段产物使用中文，机器字段、状态枚举、代码、命令和原始日志保留原值。
- 新运行编号为 `YYYYMMDDHHmmss-xxxxxxxx`，时间使用 `Asia/Shanghai`，保留八位随机后缀；Git 分支、运行目录、Docker 项目与报告共享编号。
- 主 tmux 会话命名为 `aaqe-<运行编号>`；继续验证目录归属，继续支持旧随机会话及旧阶段会话清理，不重命名历史资源。
- 使用 MIT license，版权署名使用当前仓库所有者 `qevolg`，补齐 Cargo 元数据和发布包内容。
- 参考 zitsen/atim 当前 README 的信息顺序重构文档，默认英文 `README.md`，中文 `README.zh-CN.md`，两者包含架构图、完整公开命令和配置说明，并互相链接。
- 新增带中文注释的根目录 `aaqe.yaml.example`。配置加载仍只查调用目录或显式 `--config`，不增加隐式加载或自动生成。

## 实现方式与取舍

保留现有 Rust 调度、快照、互斥、证据与清理协议；扩展现有报告渲染和命名入口。另建报告模型或迁移历史资源会引入无关兼容风险，故不采用。报告汇总仅使用当前有效候选与判定，历史重试和复现单列，不将审计 completed 等同于产品验收通过。没有 Hunter 产物时不能把空候选列表描述为完成分析。

当前报告能从权威快照重建，清理即使报告生成失败仍继续处理 Docker；这些最新行为必须保留。上海当前使用 UTC+08:00，直接使用 chrono 固定偏移生成本轮名称及带偏移时间，不依赖宿主 TZ，不新增时区库；旧时间字段仍按原值读取。

README 保持入门步骤集中、两种语言内容对应；长篇环境/MCP/证据细节移入 `docs/runtime.md`，明确其为中文参考。架构图用 Mermaid 展示宿主调度、后台阶段、受检查测试补丁、Docker Runner 和证据目录。
